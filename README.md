# Controle de Níveis de Água - Recuperação Agenda 11

Repositório criado para a entrega da atividade de recuperação da Agenda 11 do curso Técnico em Desenvolvimento de Sistemas (ETEC).

## 📋 Descrição do Projeto
O sistema consiste em uma aplicação executada no terminal em linguagem **Python** que simula o monitoramento de um reservatório de água dividido em cinco níveis de alerta. A ferramenta utiliza a biblioteca `colorama` para estilizar as saídas de texto de acordo com a gravidade de cada situação.

## 🛠️ Tecnologias Utilizadas
* **Python 3.x**
* **Biblioteca Colorama** (para formatação e cores no terminal)

## 📊 Níveis de Monitoramento
| Nível | Situação | Cor Sugerida |
| :--- | :--- | :--- |
| **Nível 1** | Muito baixo (crítico) | Vermelho (`Fore.RED`) |
| **Nível 2** | Baixo | Amarelo (`Fore.YELLOW`) |
| **Nível 3** | Médio | Verde (`Fore.GREEN`) |
| **Nível 4** | Alto | Ciano (`Fore.CYAN`) |
| **Nível 5** | Muito alto (alerta) | Azul (`Fore.BLUE`) |
